Idempotency

A property of an operation where performing it multiple times has the same effect as performing it once — e.g. an HTTP PUT that sets a resource to a given state is idempotent.

PL: Idempotentność

Właściwość operacji, w której jej wielokrotne wykonanie daje taki sam efekt jak wykonanie jej raz — np. metoda HTTP PUT ustawiająca zasob na dany stan jest idempotentna.
